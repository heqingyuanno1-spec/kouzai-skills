# 分镜脚本生成器

将完整剧本转换为可拍摄的分镜脚本，输出结构完整、可直接用于拍摄或 AI 视频生成的分镜表。

## 输入

- 完整剧本（文本）
- 可选：风格参考、时长要求、画幅比例

## 输出格式

分镜脚本以表格/结构化清单呈现，每个镜头包含以下字段：

| 字段 | 说明 |
|------|------|
| 镜头编号 | SC-001 起始，顺序递增 |
| 分镜时长 | 以秒为单位，建议 2-8 秒/镜头 |
| 景别 | 远景/全景/中景/近景/特写/大特写 |
| 镜头运动 | 固定/推/拉/摇/移/跟/升降/环绕 |
| 画面构图 | 主体位置、光线方向、环境要素 |
| 人物动作 | 镜头内人物的主要动作与走位 |
| 人物台词 | 该镜头内的对白（如有） |
| 情绪氛围 | 该镜头的情绪基调与节奏 |

## 分镜流程

1. **拆场**：将剧本按场景（地点+时间）拆分为场次
2. **定镜头**：每场按叙事节奏拆分为若干镜头，重点戏份镜头加密
3. **配景别**：根据信息量与情绪选择景别，对话场景常用中近景交替
4. **定运动**：静态对话用固定镜头，情绪爆发/节奏变化用运动镜头
5. **写构图**：明确主体、陪体、前景背景关系
6. **补细节**：补全动作、台词、情绪氛围，确保单镜头可直接拍摄

## 规则

- 单镜头信息密度适中，一个镜头表达一个核心动作或信息
- 对话场景遵循 180 度轴线原则，避免跳轴
- 动作戏注意节奏，快切镜头（1-2 秒）与慢镜头交替
- 台词嵌入镜头内，标注"角色说：xxx"格式，便于后期语音对齐
- 场景转换处可加转场提示（硬切/叠化/闪回）
